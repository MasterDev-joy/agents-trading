# 🤖 Agent Trading

Agent de trading automatisé qui analyse le marché crypto en temps réel en combinant **analyse technique** et **analyse de sentiment par IA locale**.

## 🎯 Fonctionnalités

- 📊 **Analyse technique** : RSI, MACD, Bandes de Bollinger
- 🧠 **Analyse IA** : Sentiment des actualités via Ollama (100% local)
- 🛡️ **Gestion du risque** : Stop-Loss, Take-Profit, limite quotidienne
- 📱 **Alertes Discord** : Notifications automatiques sur signaux forts
- 📈 **Backtesting** : Test de stratégie sur données historiques
- 🔧 **Optimisation** : Recherche automatique des meilleurs paramètres (Optuna)
